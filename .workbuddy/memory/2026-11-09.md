# 2026-11-09

## LanRoom（局域网通知房间）从 0 搭建

**位置**：`C:\Users\fjkj\Desktop\lan-room`（Tauri 2 + React 19 + TS + Tailwind 4 + Vite）

### 关键决策
- **局域网协议**：UDP 47932 广播，纯 P2P 无中心服务器。四种包：`Presence`（2s 心跳，承载房间名/成员）、
  `Notify`、`Ack`（单播回执）、`Bye`。成员 7s 无心跳过期；房主 = 最早加入者（自动继任）。
- **设置**：Rust 侧 JSON（`%APPDATA%\com.mahirofox.lanroom\settings.json`），非 tauri-plugin-store。
- **通知**：`tauri-plugin-notification`，Rust 侧调用（免 ACL），失败通过 `toast-error` 事件回传前端。
- **快捷键**：`tauri-plugin-global-shortcut`，自写解析器把 `"Ctrl+Alt+D"` 转 `Shortcut`；
  首选组合被占用时按 `D → F9 → Ctrl+Shift+F9 → Ctrl+Alt+M` 回退并持久化 + 界面提示。
- **回执**：收到首个 Ack 后延迟 900ms 汇总弹一条 toast，避免刷屏。
- **单例**：`tauri-plugin-single-instance` 必须第一个注册。
- **托盘**：关闭窗口 `prevent_close + hide`；托盘菜单含 显示/发送/设置/检查更新/退出。
- **自动更新**：GitHub Release `latest.json`，minisign 签名。私钥在 `.tauri/lanroom.key`（密码 `lanroom-2026`，已 gitignore），
  公钥在 `tauri.conf.json` 的 `plugins.updater.pubkey`。

### 这台机器的坑（重要）
- **没有 MSVC / VS Build Tools**，且无管理员权限。解决：装 `stable-x86_64-pc-windows-gnu` 工具链作为 host
  （`rustup toolchain install stable-x86_64-pc-windows-gnu`）+ winlibs 便携 mingw（`%LOCALAPPDATA%\lanroom-tools\mingw64`）。
  构建命令需 `RUSTUP_TOOLCHAIN=stable-x86_64-pc-windows-gnu`，链接器配置在 `src-tauri/.cargo/config.toml`。
- `crate-type` 改成只有 `rlib`：`cdylib` 在 mingw 下会 `export ordinal too large`。
- NSIS 打包需预置工具链到 `%LOCALAPPDATA%\tauri\NSIS\`，且插件必须在
  `Plugins/x86-unicode/additional/nsis_tauri_utils.dll`（GitHub 下载常 504，走 api.github.com assets 接口可下）。
- 本机 `Ctrl+Alt+D` 已被其他程序占用，所以默认快捷键会自动回退到 `Ctrl+Alt+F9`。

### 验证方式
- 前端：`VITE_MOCK=1` + `chrome --headless --screenshot` 截图核对（app 内无截图能力）。
- 协议：`scripts/test-peer.cjs` 模拟第二个节点，验证 发现→加入→广播→回执 全链路（含全局快捷键触发）。
